## 1. 论文概述

**【Paper】** 这篇工作面向 ML-KEM、ML-DSA 等格基 PQC 中反复出现的 NTT/INTT 核心，而不是完整的 KEM 或签名处理器。作者从一个可运行时配置模数的 parallel iterative NTT 加速器出发，重新设计统一蝶形单元（butterfly functional unit，BFU）：允许系数落在扩展冗余范围内，取消乘法后和中间减法后的条件修正；同时把 INTT 的缩放操作并入已有加法路径，并将 Montgomery 乘法拆成适合 FPGA DSP 的层次化结构。<a data-cite="paper" data-locator="p. 2–3, Section 1" href="#ref-paper">[1] p. 2–3, Section 1</a>

### 一句话总结

**【Paper】** 用 $R>8q$ 的冗余 Montgomery 表示把 NTT 与 INTT 的中间值统一放宽到 $[0,2q-1]$，再用 parity-aware 的加法/除二融合和 DSP 友好的 Montgomery 乘法，换掉关键路径上的连续条件修正，从而在相同流水深度下获得更高频率。<a data-cite="paper" data-locator="p. 16–22, Sections 3.2–3.4" href="#ref-paper">[1] p. 16–22, Sections 3.2–3.4</a>

### 核心贡献

**【Paper】**

1. **统一冗余算术。** 把已有的冗余 Montgomery 乘法范围分析扩展到 INTT 中的 $(a-b+2q)\omega^k$，使同一个 BFU 可以在 NTT 和 INTT 模式下都省略乘法后修正，并进一步省略该 subtract–multiply 路径上的中间减法修正。<a data-cite="paper" data-locator="p. 16–20, Section 3.2, Figure 7" href="#ref-paper">[1] p. 16–20, Section 3.2, Figure 7</a>
2. **缩放与加法融合。** INTT 的一个除二被转移到离线 twiddle 预计算，另一个除二利用 $q$ 为奇素数的 parity 关系并入模加路径，避免独立 scaling unit。<a data-cite="paper" data-locator="p. 20–22, Section 3.3, Figures 8–9" href="#ref-paper">[1] p. 20–22, Section 3.3, Figures 8–9</a>
3. **DSP-centric 宽乘法。** 对 17-bit 输入用 3 个 DSP 构造 Montgomery 乘法；对覆盖 ML-DSA 的 34-bit 输入进行层次化拆分，完整 Montgomery multiplier 使用 11 个 DSP，并通过六级流水满足 PE 阵列的低延迟约束。<a data-cite="paper" data-locator="p. 22–25, Section 3.4, Figures 10–11" href="#ref-paper">[1] p. 22–25, Section 3.4, Figures 10–11</a>
4. **端到端设计空间。** 在 Virtex-7 上评估 $N=256,512,1024$、一维和二维 PE 阵列，并报告 14-bit 与 31-bit 模数宽度下的资源、周期、频率、延迟和功耗。<a data-cite="paper" data-locator="p. 27–31, Tables 2–4" href="#ref-paper">[1] p. 27–31, Tables 2–4</a>

## 2. 背景与相关工作

**【Paper】** NTT 把多项式乘法从系数域的卷积转到 evaluation domain 的逐点乘法；radix-2 蝶形反复执行模加、模减以及 twiddle factor 的模乘。硬件因此通常在两条路线上取舍：parallel iterative 架构用多 BFU 和多 bank memory 迭代复用同一个 NTT 数据流，pipelined 架构则用 SDF/MDC 等延迟网络减少不规则访存。无论选择哪一类，Barrett 或 Montgomery reduction 后的条件修正都会增加逻辑深度，INTT 还额外需要除以 $N$ 的缩放。<a data-cite="paper" data-locator="p. 4–12, Section 2" href="#ref-paper">[1] p. 4–12, Section 2</a>

作者把自己的位置放在已有的 unified butterfly、conflict-free memory mapping 和冗余表示的交叉处：PE 阵列和访存调度主要继承可配置 parallel NTT 的路线，新的重点是让 BFU 的算术输出不必在每一个局部操作之后回到 canonical range。论文特别比较了 runtime-configurable 设计、固定模数设计、BRAM-free 设计以及 DSP-heavy 设计，但没有声称跨所有 NTT 加速器“绝对最优”。<a data-cite="paper" data-locator="p. 6–12, Sections 2.1–2.4" href="#ref-paper">[1] p. 6–12, Sections 2.1–2.4</a>

**【Analysis】** 这篇论文的价值更接近 arithmetic/microarchitecture co-design，而不是新的 NTT 数学变换：它接受标准 radix-2 NTT 的数据流和已有的 conflict-free memory schedule，集中改变“结果什么时候必须被修正、缩放什么时候发生、宽乘法如何落到 DSP”这三个接口。收益的来源也因此比较可解释；代价则是所有中间信号多出 3 bit，并且最终优势依赖于 FPGA 的 DSP 形状、布线以及 PE 阵列能否消化这些宽 datapath。

## 3. 问题定义

**【Paper】** 对长度为 $N$、模数为 $q$ 的多项式，radix-2 蝶形把两个输入 $a,b$ 和一个 twiddle factor $\omega^k$ 变成：

$$
\begin{aligned}
a' &= a + b\omega^k \pmod q,\\
b' &= a - b\omega^k \pmod q.
\end{aligned}
$$

INTT 使用相反方向的 twiddle，并在相应路径中完成除二；完整变换还需要最终的 $N^{-1}$ 缩放。论文将每个系数放在 Montgomery form，输入的 canonical 宽度为 $W=\lceil\log_2q\rceil$，但目标 BFU 不承担“每个小操作后都 canonicalize”的职责。<a data-cite="paper" data-locator="p. 4–5, Section 2" href="#ref-paper">[1] p. 4–5, Section 2</a>

实现边界可以明确成四点：

- **运算范围：** NTT/INTT kernel 及其 BFU/PE 阵列，不是完整 ML-KEM 或 ML-DSA 协议。
- **表示：** 所有输入、中间量和输出采用 Montgomery form；冗余版本允许同一个 residue 由 $x$ 或 $x+q$ 表示。
- **参数化：** BFU 支持运行时更换模数与预计算 twiddle，数据宽度决定可支持的模数范围；论文实验覆盖最多 14-bit 和 31-bit 模数。
- **优化目标：** 在不增加 PE 流水深度的前提下，减少 correction/scaling 的关键路径，获得更高 Fmax 与更低绝对执行时间。

作者要求 NTT 模数是能提供所需 root of unity 的奇素数，满足 $q\equiv1\pmod{2N}$；运行时更换模数时只需加载对应的离线 twiddle 表，datapath 不变。<a data-cite="paper" data-locator="p. 18–20, Section 3.2" href="#ref-paper">[1] p. 18–20, Section 3.2</a>

## 4. 方法

### 4.1 Overall Architecture

**【Paper】** 加速器沿用 parallel iterative NTT：$w\times d$ 个 PE 排成二维网格，每个 PE 包含一个统一 BFU；数据从左向右穿过 butterfly-style interconnect，同列 PE 之间不互连，输入从 memory 读入，经过多个 PE 后写回 memory。作者采用已有的 conflict-free mapping，让每个系数映射到唯一 bank 和 bank 内地址，从而在迭代 NTT 中同时支撑并行计算与并行访存。<a data-cite="paper" data-locator="p. 13, Section 3, Figure 4" href="#ref-paper">[1] p. 13, Section 3, Figure 4</a>

$$
L_{PE}\leq\frac{N}{2wd2^d},
$$

其中 $L_{PE}$ 是 PE latency。低延迟 BFU 因而不仅影响单个蝶形的 Fmax，也决定 $w,d,N$ 组合中哪些配置可以保持连续数据流。<a data-cite="paper" data-locator="p. 13, Section 3" href="#ref-paper">[1] p. 13, Section 3</a>

### 4.2 核心机制：从 canonical correction 到统一冗余范围

**【Paper】** 原始 unified butterfly 同时支持 NTT/INTT，但每个模加、模减和 Montgomery 乘法都假设输入输出位于 $[0,q-1]$，所以会串接 conditional correction。论文首先允许 NTT mode 的输入落在 $[0,2q-1]$；对 INTT mode，则令 $a,b,\omega^k\in[0,2q)$，把差值改写成 $a-b+2q$，使其与 $a+b$ 一样落在 $[0,4q)$ 的中间范围。<a data-cite="paper" data-locator="p. 15–19, Section 3.2, Figure 6" href="#ref-paper">[1] p. 15–19, Section 3.2, Figure 6</a>

令 Montgomery radix 为 $R$，并记 $\mu=-q^{-1}\pmod R$。对 INTT 的 subtract–multiply，论文给出的 Montgomery 形式是：

$$
\overline{b'_{INTT}}
=\frac{\overline{(a-b+2q)}\,\overline{\omega^k}
+q[\overline{(a-b+2q)}\,\overline{\omega^k}\,\mu]_R}{R}.
$$

由于 $\overline{(a-b+2q)}<4q$、$\overline{\omega^k}<2q$，乘积上界为 $8q^2$；再利用余数项的上界，论文得到：

$$
0\leq\overline{b'_{INTT}}\leq q+\frac{8q^2}{R}.
$$

当 $R>8q$ 时，结果仍然落在 $[0,2q]$。于是乘法后 correction 和 subtractor 到 multiplier 之间的 correction 都可去掉；最终只需在蝶形输出端保留把结果拉回 $[0,2q-1]$ 的加/减修正。所有信号宽度增加为 $W_{red}=\lceil\log q\rceil+3$，并把 $R$ 选成大于 $8q$ 的下一个二次幂。<a data-cite="paper" data-locator="p. 17–20, Equations (1)–(9), Figure 7" href="#ref-paper">[1] p. 17–20, Equations (1)–(9), Figure 7</a>

**【Analysis】** 这里的关键是“中间值不再独立可见”。$a-b+2q$ 暂时可以超过 $2q-1$，因为它马上进入 Montgomery multiplier，论文只需要证明组合后的输出重新回到统一冗余范围。这比单纯把每个 reducer 放宽更强：它改变了 correction 的依赖边界，把一段串行逻辑变成 multiplier 的输入契约。不过它也把正确性责任集中到 range proof 和所有后续消费者的接口约束上；如果将该中间节点复用于别的 datapath，当前证明不能直接复用。

### 4.3 INTT 缩放：离线 twiddle 与 parity-aware 加法

**【Paper】** 原 unified BFU 在 INTT 中有两个 divide-by-2 单元。第一处被转移到预处理：不再存储 $\omega^{-k}$，而是离线计算 $\omega^{-k}/2\pmod q$ 后写入 twiddle memory，因此运行时 multiplier 直接得到带缩放的常数。第二处位于 adder 输出，论文将模加与除二融合：加法器生成 $sum$ 和 $sum-2q$，再根据 $sum$ 的范围与奇偶决定加 $q$、减 $q$、减 $2q$ 或不修正，最后右移一位。<a data-cite="paper" data-locator="p. 20–22, Section 3.3, Figures 8–9" href="#ref-paper">[1] p. 20–22, Section 3.3, Figures 8–9</a>

### 4.4 算术与数据通路：从 17-bit 到 34-bit DSP 映射

**【Paper】** Montgomery multiplication 需要两个宽乘法、一个模 $R$ 的乘法和一次加法。论文针对 Xilinx DSP48E1 的 signed $25\times18$ 乘法与 48-bit accumulate 结构，不直接把 34-bit 乘法当作一个大黑盒，而是把它拆成 17-bit 子乘法。

| datapath | 论文中的映射 | BFU 级含义 |
| --- | --- | --- |
| $\leq17$ bit | 两个普通乘法各占 1 个 DSP，multiply-add 阶段占 1 个 DSP | 一个完整 Montgomery multiplier 使用 3 个 DSP |
| 34 bit | 每个宽乘法拆成四个 17-bit 子乘法，再用 carry-save/carry-propagate adder 合并 | 支持最多 31-bit 模数的冗余 BFU |
| 模 $R$ 的乘法 | $R$ 为二次幂，最高位子乘法对最终低位结果没有贡献 | 第二个宽乘法少用一个 DSP |
| multiply-add | 使用 DSP 内部的 accumulate，避免额外 carry-save stage | 总计 11 个 DSP |

### 5.3 资源与效率分析

**【Paper】** 论文的原始数据呈现出三个稳定趋势：$N$ 从 256 增长到 1024 时 cycles 近似按 $O(N\log N)$ 增长；模数位宽增大主要推高 LUT、FF、DSP，而不明显改变 cycle count；增加一维 PE 数量能显著降低 cycles，却会带来 LUT、DSP、BRAM 和频率下降。以 14-bit、$N=1024$ 为例，$1\times1$ 到 $32\times1$ 使 cycles 从 5128 降为 168，但 LUT 从 592 增至 139172，频率从 424 MHz 降至 210 MHz。<a data-cite="paper" data-locator="p. 29–31, Table 3" href="#ref-paper">[1] p. 29–31, Table 3</a>

**【Analysis】** 用同一设计点重算 $\mathrm{latency}_{\mu s}=\mathrm{cycles}/\mathrm{frequency}_{MHz}$：5128/424=12.0943 μs，与论文报告的 12.1 μs 一致；5128/380=13.4947 μs，与 31-bit 的 13.5 μs 一致。对于 14-bit、$N=1024$，$8\times2$ 相比 $32\times1$ 的 LUT 约减少 14.0×，但 latency 从 0.8 μs 变成 1.2 μs；这不是单纯的“更快”，而是用约 50% 的延迟增加换取一个数量级的资源下降。论文的 35%–73% 延迟改善应理解为对照表中匹配的 FPGA、NTT size、模数宽度和 PE 配置的结果，不能脱离这些边界外推成所有 NTT 加速器的统一倍率。<a data-cite="paper" data-locator="p. 3, 27–31, Sections 1 and 4" href="#ref-paper">[1] p. 3, 27–31, Sections 1 and 4</a>

功耗只在本文设计的 Table 3 行中出现，对比工作没有报告功耗；论文也没有在表格附近明确功耗是板级测量、工具估算还是仅某个模块边界。因此本文保留原始 W 数值，但不把它当作与其他工作的可比 energy/op，也不把二维阵列的功耗优势当作已经完成的独立测量结论。

### 5.4 Ablation / Design-Space Exploration

**【Paper】** 论文没有给出逐项去掉“冗余表示、除二融合、DSP 层次映射”的严格消融表；它主要通过 BFU 对比、不同位宽、不同 $N$、不同 PE 阵列和 BRAM-free 对照来展示设计空间。与 BRAM-free 设计相比，论文的单 PE 方案用 485 LUT、343 FF、3 DSP、3 BRAM 和 2.3 μs，换来更小的 LUT/FF；$8$ PE 与 $2\times2$ 方案则把延迟降到 0.3/0.6 μs，但增加了存储资源。<a data-cite="paper" data-locator="p. 31, Table 4" href="#ref-paper">[1] p. 31, Table 4</a>

**【Analysis】** 因而无法从论文现有实验中分离出“去 correction”对 Fmax 的独立贡献，也无法确认 2D 阵列的收益中有多少来自 BFU、多少来自 memory mapping。最小的补充实验应固定 PE 阵列和 Vivado 约束，分别打开三项优化，报告 critical-path slack、LUT/DSP、cycles 和 frequency；否则只能确认组合优化有效，不能确认每项优化的边际收益。

## 6. 方法分析

### 6.1 为什么有效？

**【Analysis】** 可以把论文的因果链压缩成：

`canonical correction 串行路径 → 扩展冗余范围 → 中间值不再需要独立 canonicalize → BFU 组合逻辑更短 → 不增加流水级数也能提高 Fmax → 同一 cycle count 下 latency 下降`。

INTT 的除二融合进一步消除了一个独立模块和一个级联依赖；DSP 层次映射则让宽乘法更多地停留在 FPGA 的硬核资源内部。三者叠加后，单 BFU 的 cycle latency 没有为了补偿 correction 而增加，但数据宽度和 DSP 数量随模数范围增大，这解释了“频率提升与资源增长同时存在”的结果。

### 6.2 核心创新

**【Paper】**

1. **数学/表示层：** 用 $R>8q$ 的统一冗余范围覆盖 NTT 的乘法和 INTT 的 subtract–multiply，并证明组合输出仍回到 $[0,2q-1]$。
2. **数据通路层：** 通过 parity 与范围联合判断，把 INTT 的除二并入模加，删除独立 scaling unit。
3. **实现层：** 以 17-bit 子乘法为基本颗粒，把 Montgomery multiplier 映射到 DSP48E1，并对 34-bit 路径做 carry-save 与 DSP accumulate 协同。
4. **体系结构层：** 把低延迟 BFU 放回二维 PE 阵列和 conflict-free memory schedule，验证局部算术优化能传递到完整 NTT latency。

### 6.3 与已有方法的本质区别

**【Paper】**

| 维度 | 常见 unified / configurable NTT | 本文设计 |
| --- | --- | --- |
| 系数范围 | 通常在每个模运算后回到 $[0,q-1]$ | 允许统一的 $[0,2q-1]$ 冗余表示 |
| NTT/INTT BFU | 共享结构，但 correction 与 scaling 仍在 datapath 中 | NTT/INTT 共享 BFU，乘法后 correction 被删除，除二被融合/预计算 |
| subtract–multiply | 先做减法修正，再送入 Montgomery multiplier | 允许 $a-b+2q$ 直接进入 multiplier，由组合范围证明兜底 |
| 宽乘法 | 可能依赖通用乘法器或字级 reduction | 17-bit 子乘法、carry-save、DSP multiply-add 的层次映射 |
| 访存 | 需要处理 NTT stage 的冲突与 bubble | 沿用 conflict-free mapping，把优化重点放到 BFU latency |
| 代价 | canonical correction 的逻辑深度较高 | 多 3 bit datapath、更多 DSP，以及对 $R>8q$ 和预计算 twiddle 的依赖 |

这里的本质区别不是“使用了 Montgomery”本身，而是把表示范围作为 BFU 的接口契约：它允许 correction 从每个算术单元后面移除，而不是只在一个 reducer 内做局部优化。<a data-cite="paper" data-locator="p. 12–25, Sections 2.4 and 3" href="#ref-paper">[1] p. 12–25, Sections 2.4 and 3</a>

### 6.4 代价与适用条件

**【Paper】** 该方法需要 $R>8q$，因此所有输入、输出和中间信号增加 3 bit；模数变化时 twiddle factor 需要离线生成并重新加载；34-bit 版本为覆盖 ML-DSA 使用 11 个 DSP，明显高于 17-bit 版本的 3 个 DSP。PE 阵列还必须满足与 PE latency 相关的无 bubble 约束，否则局部 BFU 的频率收益可能被 pipeline stall 抵消。<a data-cite="paper" data-locator="p. 18–25, Sections 3.2–3.4" href="#ref-paper">[1] p. 18–25, Sections 3.2–3.4</a>

**【Analysis】** 适用条件可以具体化为：

1. FPGA 必须有足够匹配的 DSP 与 BRAM 端口；如果设计转向 LUT-only、ASIC 或另一种 DSP 形状，17/34-bit 的打包优势需要重新综合。
2. 运行时可配置模数有价值，但它会放弃固定模数 reducer 的极致专用化；在只服务 ML-KEM 的极小设备上，论文的频率优势未必抵消额外位宽。
3. 二维 PE 阵列依赖 memory mapping 和布线质量。PE 数量继续扩大后，routing pressure、频率下降和功耗会成为新的瓶颈，不能只按 BFU 数量线性推理吞吐。
4. 论文没有评估 masking、hiding、fault detection 或实际侧信道泄漏；对于真实 PQC 部署，冗余范围与数据相关的切换活动仍需单独验证。

## 7. 局限性

### 7.1 作者明确提出的局限

**【Paper】** 论文明确指出计算效率只解决部署问题的一部分，后续工作需要为 NTT 加速器加入抵抗侧信道攻击的物理安全 countermeasures。论文当前没有给出 side-channel 或 fault-injection 实验，也没有报告完整 ML-KEM/ML-DSA 协议级端到端延迟。<a data-cite="paper" data-locator="p. 37, Section 5" href="#ref-paper">[1] p. 37, Section 5</a>

### 7.2 自己分析得到的局限

**【Analysis】**

1. **缺少逐项消融。** 当前证据能证明组合设计优于若干对照点，但不能量化冗余范围、除二融合和 DSP 映射各自的贡献。
2. **实现阶段边界不够统一。** 论文说明使用 Vivado 2025.2，但没有为所有结果清楚区分 post-synthesis、post-route、板级测量与工具估算；跨工作频率比较需要把这个差异保留为证据缺口。
3. **功耗口径不完整。** 只有本文设计报告 W，且没有明确测量窗口、静态/动态组成或 I/O 边界，因此不能推出 energy/op 或功耗随吞吐的普适关系。
4. **代码可复现性有限。** 本文核验到的是论文与其 arXiv LaTeX/图像源；没有在论文页面发现作者公开的 RTL、Vivado 工程或综合约束，因此无法把 Figure 9 映射到真实模块、FSM 和 testbench。
5. **安全性尚未闭环。** 冗余值允许同一 residue 有多种表示，且 mux、加法器和 DSP 的切换活动可能改变功耗轨迹；这是需要实测而非凭 constant-time 控制推断的问题。

## 8. 启发与研究思考

**【Analysis】** 这篇工作的可复用启发不是“把所有 NTT 都改成 34 bit”，而是把表示不变量写成硬件模块接口，再据此重排 correction、scaling、DSP packing 和 memory schedule。基于论文的证据，下面两个假设适合直接做最小 RTL/综合实验：

- **假设 1：冗余范围的收益存在一个由布线主导的拐点。** 在 $W_{red}=15,17,26,34$ 的 BFU 上分别打开/关闭乘法后 correction，固定六级 Montgomery pipeline，测 critical path、LUT、DSP、slack 和功耗。若去 correction 后 Fmax 增益在更宽 datapath 上消失，或新增 3 bit 的 routing cost 超过逻辑深度收益，则说明该方法的主要适用范围是 FPGA DSP 形状匹配良好的中等宽度，而不是任意大整数 NTT。
- **假设 2：$w\times2$ 是由频率退化决定的 Pareto 区域，而非固定经验。** 对 $N=256,512,1024$ 扫描 $w\times1$ 与 $w\times2$，把 PE 数量、BRAM、DSP、Achieved Fmax 和 latency 放入同一张 Pareto 图，并显式计入 memory stall。若在换一代 FPGA 或换模数后 $w\times1$ 仍然在相同吞吐下拥有更低 ATP，则论文关于二维阵列“最实际折中”的结论只适用于当前 mapping/器件组合。
- **安全验证问题：** 对 canonical BFU 与 redundant BFU 做相同输入分布、相同频率和相同 PE 配置的 TVLA/功耗采样，再比较冗余表示与 correction 删除对泄漏的影响；如果泄漏显著变化，说明算术优化必须和保护逻辑共同设计，而不能把侧信道安全留到协议层。
